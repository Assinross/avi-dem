# Ави-Дем

Браузерная пошаговая карточная дуэль в тёмной научной фантастике. Четыре фракции, кампания из шести глав с ветвящимися картами, выбор карт после побед, редактор колоды.

Играть: https://assinross.github.io/avi-dem/

## Фракции

| Фракция | Стихия эфира | Стиль игры |
|---|---|---|
| Кланы Перелома | Хаос | прямой урон, стены, жертвы ради краткой силы |
| Рой мутаций | Жизнь | рост числа, яды, регенерация |
| Астральный Синклит | Движение | контроль, барьеры, кража эфира |
| Пограничный Союз | Синтез | техника, ремонт, подкрепления из могильника |

## Как играть

- Ход: розыгрыш карт -> выбор атакующих -> защитник назначает блоки -> схватки.
- Эфир растёт каждый ход по уровню героя, неистраченный сгорает.
- В схватке атакующий бьёт первым, защитник отвечает, если выжил. Первый удар меняет порядок.
- Правый клик или Esc - отмена выбора. Наведение на существо показывает карту и пояснения ключевых слов.
- Кампания: герой растёт в уровне за опыт. Если зачистить всю главу, к рубежу придёте ровно уровнем стража.

Подробные правила - [docs/rules.md](docs/rules.md).

## Запуск локально

Статика без сборки. Данные грузятся через `fetch`, поэтому нужен локальный сервер:

```bash
python3 -m http.server 8068
```

Открыть http://localhost:8068

## Тесты

```bash
node tests/run.js
```

## Структура

- `index.html`, `style.css` - страница и стили
- `js/` - `engine.js` (правила боя), `effects.js` (способности), `ai.js` (ИИ), `campaign.js` (кампания), `ui.js` (экран боя), `screens.js`, `deck.js`, `save.js`, `assets.js`, `main.js`
- `data/` - карты, монстры, фракции, кампания, таблицы опыта и эфира
- `assets/` - арт (пока заглушки: рамка стихии и руна)
- `tools/` - скрипты подготовки данных
- `tests/` - тесты движка, карт и кампании

## Права

Игровая механика вдохновлена классическими карточными дуэлями. Все названия, тексты, фракции и оформление - оригинальные.
